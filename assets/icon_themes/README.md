# Style icon themes

Folder and place icons used by the Sweet and Dracula styles
(`lib/core/theme/app_style.dart`). Both are GPL-3.0, like Explorer; each
folder has its LICENSE.

- `sweet/`: [Sweet folders](https://github.com/EliverLara/Sweet-folders),
  Sweet-Rainbow, Places/48, by Eliver Lara.
- `dracula/`: [Dracula Icons](https://github.com/m4thewz/dracula-icons),
  scalable/places, by Matheus Vitor (recoloured Papirus icons).

`user-desktop.svg` in `dracula/` is a copy of its `folder-desktop.svg`, so
both packs have the same names.
